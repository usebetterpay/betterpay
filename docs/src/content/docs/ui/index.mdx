`@betterpay/ui` is the presentational React layer for BetterPay billing surfaces. Drop components into your app, pass domain-shaped props, and wire callbacks to `@betterpay/billing` or your own API.

## Why a UI package

Billing UI is deceptively hard: interval toggles, status vocabulary, IDR formatting, empty states, and accessible dialogs. This package gives you production patterns that match BetterPay's domain model (subscriptions, entitlements, invoices) without owning checkout — payment links still come from Midtrans Snap, Xendit, and friends.

## Principles

- **IDR-first** — default locale `id-ID`, tabular money via `formatMoney`
- **Domain status** — `scheduled` · `active` · `past_due` · `canceled` · `ended` (and invoice statuses)
- **Base UI + base-nova** — `render` composition, not Radix `asChild`
- **Presentational** — props in, callbacks out; no hardcoded provider SDK
- **Composable** — compound pieces (`PlanCard` / `PlanGroup`) plus opinionated sections (`PricingTable`, `BillingPortal`)

## Install

```bash
pnpm add @betterpay/ui react react-dom
```

Optional CSS variables if your app is not already themed:

```ts
import '@betterpay/ui/styles.css';
```

Host apps should provide Tailwind (or equivalent) for utility classes used by components.

## Quick example

```tsx
import { PricingTable, type PlanView } from '@betterpay/ui';

const plans: PlanView[] = [
  {
    id: 'free',
    name: 'Free',
    monthlyAmount: 0,
    yearlyAmount: 0,
    currency: 'IDR',
    features: [{ id: 'msg', label: '100 messages / month' }],
    ctaLabel: 'Start free',
  },
  {
    id: 'pro',
    name: 'Pro',
    monthlyAmount: 199_000,
    yearlyAmount: 1_990_000,
    currency: 'IDR',
    recommended: true,
    badge: 'Popular',
    features: [
      { id: 'msg', label: '5.000 messages / month' },
      { id: 'wa', label: 'WhatsApp notifications' },
    ],
    ctaLabel: 'Upgrade to Pro',
  },
];

export function PricingPage() {
  return (
    <PricingTable
      plans={plans}
      onSelectPlan={(planId, interval) => {
        // await pay.billing.subscribe({ customerId, planId })
        console.log(planId, interval);
      }}
    />
  );
}
```
