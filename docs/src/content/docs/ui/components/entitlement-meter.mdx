---
title: Entitlement Meter
description: Linear usage meter for a single metered feature.
---

`EntitlementMeter` shows used / limit with a progress track and optional reset label.

<ComponentPreview
  code={`import { EntitlementMeter } from '@betterpay/ui';

<EntitlementMeter
  entitlement={{
    featureId: 'messages',
    label: 'Messages',
    used: 1240,
    limit: 5000,
    resetLabel: 'monthly',
  }}
/>`}
>
  <DemoEntitlementMeter />
</ComponentPreview>

## Installation

```bash
pnpm add @betterpay/ui
```

## API Reference

### EntitlementMeter

| Prop | Type | Default |
| --- | --- | --- |
| `entitlement` | `EntitlementView` | — |
| `warnAt` | `number` (0–1) | `0.15` |
