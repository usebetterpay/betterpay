## Usage

```tsx title="Import"
import { EntitlementMeter, type EntitlementView } from '@betterpay/ui';
```

```tsx title="Basic"
<EntitlementMeter
  entitlement={{
    featureId: 'messages',
    label: 'Messages',
    used: 1240,
    limit: 5000,
    resetLabel: 'monthly',
  }}
  warnAt={0.15}
/>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `entitlement` | `EntitlementView` | — | Feature usage |
| `warnAt` | `number` (0–1) | `0.15` | Warn when remaining ratio ≤ this |
