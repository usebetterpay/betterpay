## Usage

```tsx title="Import"
import { UsageSummary } from '@betterpay/ui';
```

```tsx title="Basic"
<UsageSummary
  entitlements={entitlements}
  periodLabel="12 days left in cycle"
  collapseAfter={2}
/>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `entitlements` | `EntitlementView[]` | — | Meters |
| `title` | `string` | `"Usage"` | Heading |
| `periodLabel` | `string` | — | Cycle hint |
| `collapseAfter` | `number` | `3` | `0` = never collapse |
