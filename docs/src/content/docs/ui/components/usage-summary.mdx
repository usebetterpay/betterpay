---
title: Usage Summary
description: Multi-entitlement usage panel with optional expand for long lists.
---

`UsageSummary` stacks meters, shows a cycle period label, and can collapse after N items. Try **Show more** in the preview.

<ComponentPreview
  code={`import { UsageSummary } from '@betterpay/ui';

<UsageSummary
  entitlements={entitlements}
  periodLabel="12 days left in cycle"
  collapseAfter={2}
/>`}
>
  <DemoUsageSummary />
</ComponentPreview>

## Installation

```bash title="Terminal"
pnpm add @betterpay/ui
```

## API Reference

### UsageSummary

| Prop | Type | Default |
| --- | --- | --- |
| `entitlements` | `EntitlementView[]` | — |
| `title` | `string` | `"Usage"` |
| `periodLabel` | `string` | — |
| `collapseAfter` | `number` | `3` (`0` = never) |
