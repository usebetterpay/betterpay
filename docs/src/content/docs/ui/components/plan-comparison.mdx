`PlanComparison` renders a table of features against plans. Cells support included, excluded, partial, or custom text.

## Installation

```bash
pnpm add @betterpay/ui
```

```tsx
import { PlanComparison, type ComparisonFeatureRow } from '@betterpay/ui';
```

## Examples

### Explicit feature matrix

```tsx
const features: ComparisonFeatureRow[] = [
  {
    id: 'msg',
    label: 'Messages / month',
    values: { free: '100', pro: '5.000', enterprise: 'Unlimited' },
  },
  {
    id: 'wa',
    label: 'WhatsApp',
    values: { free: false, pro: true, enterprise: true },
  },
];

<PlanComparison plans={plans} features={features} interval="year" />
```

## API Reference

### PlanComparison

| Prop | Type | Default |
| --- | --- | --- |
| `plans` | `PlanView[]` | — |
| `features` | `ComparisonFeatureRow[]` | derived |
| `interval` | `"month" \| "year"` | `"month"` |
| `onSelectPlan` | `(planId: string) => void` | — |
| `currencyFallback` | `string` | `"IDR"` |

### ComparisonCell

`true` · `false` · `"partial"` · `string`
