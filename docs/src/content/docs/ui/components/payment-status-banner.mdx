## Usage

```tsx title="Import"
import { PaymentStatusBanner } from '@betterpay/ui';
```

```tsx title="Variants"
<PaymentStatusBanner status="success" description="Paid via BCA VA." />
<PaymentStatusBanner status="past_due" description="Update payment." />
<PaymentStatusBanner status="failed" dismissible onDismiss={...} />
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `status` | `"success" \| "failed" \| "past_due" \| "pending"` | — | Tone |
| `title` | `string` | from status map | Heading |
| `description` | `string` | — | Body |
| `dismissible` | `boolean` | `false` | Show dismiss |
| `onDismiss` | `() => void` | — | Dismiss handler |
| `action` | `ReactNode` | — | Optional CTA |
