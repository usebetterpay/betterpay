---
title: Payment Status Banner
description: Callout for success, failed, past due, or pending payments.
---

`PaymentStatusBanner` is a full-border tinted callout. Status is always labeled in text.

<ComponentPreview
  code={`import { PaymentStatusBanner } from '@betterpay/ui';

<PaymentStatusBanner
  status="success"
  description="Invoice paid via BCA VA."
/>`}
>
  <DemoPaymentStatusBanner />
</ComponentPreview>

## Installation

```bash title="Terminal"
pnpm add @betterpay/ui
```

## API Reference

### PaymentStatusBanner

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"success" \| "failed" \| "past_due" \| "pending"` | — |
| `title` | `string` | from status map |
| `description` | `string` | — |
| `dismissible` | `boolean` | `false` |
| `onDismiss` | `() => void` | — |
| `action` | `ReactNode` | — |
