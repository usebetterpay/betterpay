---
title: Payment Status Banner
description: Callout for success, failed, past due, or pending payments.
---

`PaymentStatusBanner` is a full-border tinted callout (no side-stripe accents). Status is always labeled in text, not color alone.

## Installation

```bash
pnpm add @betterpay/ui
```

```tsx
import { PaymentStatusBanner } from '@betterpay/ui';
```

## Examples

### Success

```tsx
<PaymentStatusBanner
  status="success"
  description="Invoice INV-2026-001 was paid via BCA VA."
/>
```

### Failed

```tsx
<PaymentStatusBanner
  status="failed"
  title="Payment failed"
  description="The virtual account expired. Generate a new payment link."
  dismissible
  onDismiss={() => setBanner(null)}
/>
```

### Past due with action

```tsx
<PaymentStatusBanner
  status="past_due"
  description="Update payment to keep Pro features."
  action={<Button size="sm">Retry payment</Button>}
/>
```

### Pending

```tsx
<PaymentStatusBanner status="pending" description="Waiting for bank confirmation." />
```

## API Reference

### PaymentStatusBanner

| Prop | Type | Default |
| --- | --- | --- |
| `status` | `"success" \| "failed" \| "past_due" \| "pending"` | — |
| `title` | `string` | from status map |
| `description` | `string` | — |
| `dismissible` | `boolean` | `false` |
| `onDismiss` | `() => void` | — |
| `action` | `ReactNode` | — |
| `className` | `string` | — |
