## Usage

```tsx title="Import"
import { InvoiceCard, InvoiceCardList } from '@betterpay/ui';
```

```tsx title="List"
<InvoiceCardList invoices={invoices} onDownload={handleDownload} />
```

## Props

### InvoiceCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `invoice` | `InvoiceView` | — | Invoice data |
| `onDownload` | `(invoiceId) => void` | — | Download action |
| `compact` | `boolean` | `false` | Tighter padding |

### InvoiceCardList

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `invoices` | `InvoiceView[]` | — | Cards |
| `onDownload` | `(invoiceId) => void` | — | Download action |
| `emptyMessage` | `string` | `"No invoices yet."` | Empty state |
