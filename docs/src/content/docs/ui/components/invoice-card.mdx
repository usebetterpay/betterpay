---
title: Invoice Card
description: Single invoice row for mobile lists and dense stacks.
---

`InvoiceCard` shows one invoice as a horizontal card. `InvoiceCardList` stacks many.

<ComponentPreview
  code={`import { InvoiceCard, InvoiceCardList } from '@betterpay/ui';

<InvoiceCard invoice={invoice} onDownload={...} />
<InvoiceCardList invoices={invoices} onDownload={...} />`}
>
  <DemoInvoiceCard />
</ComponentPreview>

## Installation

```bash title="Terminal"
pnpm add @betterpay/ui
```

## API Reference

### InvoiceCard

| Prop | Type | Default |
| --- | --- | --- |
| `invoice` | `InvoiceView` | — |
| `onDownload` | `(invoiceId: string) => void` | — |
| `compact` | `boolean` | `false` |

### InvoiceCardList

| Prop | Type | Default |
| --- | --- | --- |
| `invoices` | `InvoiceView[]` | — |
| `onDownload` | `(invoiceId: string) => void` | — |
| `emptyMessage` | `string` | `"No invoices yet."` |
