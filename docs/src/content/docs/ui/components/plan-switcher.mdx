---
title: Plan Switcher
description: Dialog to select a different plan for an existing subscription.
---

`PlanSwitcher` opens a dialog listing available plans and confirms a change. Click the button in the preview.

<ComponentPreview
  code={`import { PlanSwitcher } from '@betterpay/ui';

<PlanSwitcher
  plans={plans}
  currentPlanId="pro"
  onConfirm={(planId) => {}}
/>`}
>
  <DemoPlanSwitcher />
</ComponentPreview>

## Installation

```bash
pnpm add @betterpay/ui
```

## API Reference

### PlanSwitcher

| Prop | Type | Default |
| --- | --- | --- |
| `plans` | `PlanView[]` | — |
| `currentPlanId` | `string` | — |
| `interval` | `"month" \| "year"` | `"month"` |
| `triggerLabel` | `string` | `"Change plan"` |
| `onConfirm` | `(planId: string) => void` | — |
| `open` | `boolean` | — |
| `onOpenChange` | `(open: boolean) => void` | — |
