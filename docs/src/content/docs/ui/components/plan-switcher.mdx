## Usage

```tsx title="Import"
import { PlanSwitcher } from '@betterpay/ui';
```

```tsx title="Basic"
<PlanSwitcher
  plans={plans}
  currentPlanId={subscription.planId}
  interval="month"
  onConfirm={handleChange}
/>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `plans` | `PlanView[]` | — | Available plans |
| `currentPlanId` | `string` | — | Active plan |
| `interval` | `"month" \| "year"` | `"month"` | Price period |
| `triggerLabel` | `string` | `"Change plan"` | Button label |
| `onConfirm` | `(planId) => void` | — | Confirm handler |
| `open` | `boolean` | — | Controlled open |
| `onOpenChange` | `(open) => void` | — | Open change |
