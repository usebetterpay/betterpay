## Usage

```tsx title="Import"
import { PricingTable, type PlanView } from '@betterpay/ui';
```

```tsx title="Basic"
<PricingTable
  plans={plans}
  title="Simple pricing"
  description="IDR pricing for Indonesian products."
  onSelectPlan={(planId, interval) => {
    // pay.billing.subscribe(...)
  }}
/>
```

```tsx title="Controlled interval"
<PricingTable
  plans={plans}
  interval={interval}
  onIntervalChange={setInterval}
  density="compact"
  onSelectPlan={handleSelect}
/>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `plans` | `PlanView[]` | — | Plans to render |
| `title` | `string` | `"Choose a plan"` | Heading |
| `description` | `string` | IDR default copy | Subheading |
| `interval` | `"month" \| "year"` | — | Controlled period |
| `defaultInterval` | `"month" \| "year"` | `"month"` | Uncontrolled default |
| `onIntervalChange` | `(interval) => void` | — | Period change |
| `onSelectPlan` | `(planId, interval) => void` | — | CTA |
| `currencyFallback` | `string` | `"IDR"` | Fallback currency |
| `density` | `"comfortable" \| "compact"` | `"comfortable"` | Spacing |
