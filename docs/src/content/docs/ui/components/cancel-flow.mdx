```

/>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `planName` | `string` | — | Plan label in copy |
| `triggerLabel` | `string` | `"Cancel subscription"` | Button label |
| `reasons` | `{ id, label }[]` | built-in | Optional leave reasons |
| `onConfirm` | `(payload) => void` | — | Confirm handler |
| `open` | `boolean` | — | Controlled open |
| `onOpenChange` | `(open) => void` | — | Open change |
