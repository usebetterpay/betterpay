---
title: Cancel Flow
description: Confirm subscription cancellation with optional leave reason.
---

`CancelFlow` is a destructive confirmation dialog. Open it from the preview button.

<ComponentPreview
  code={`import { CancelFlow } from '@betterpay/ui';

<CancelFlow
  planName="Pro"
  onConfirm={({ reasonId }) => {}}
/>`}
>
  <DemoCancelFlow />
</ComponentPreview>

## Installation

```bash
pnpm add @betterpay/ui
```

## API Reference

### CancelFlow

| Prop | Type | Default |
| --- | --- | --- |
| `planName` | `string` | — |
| `triggerLabel` | `string` | `"Cancel subscription"` |
| `reasons` | `{ id: string; label: string }[]` | built-in set |
| `onConfirm` | `(payload: { reasonId?: string }) => void` | — |
| `open` | `boolean` | — |
| `onOpenChange` | `(open: boolean) => void` | — |
