## Usage

```tsx title="Import"
import { SubscriptionSummary, type SubscriptionView } from '@betterpay/ui';
```

```tsx title="Basic"
<SubscriptionSummary
  subscription={subscription}
  onUpgrade={openPlanSwitcher}
  onCancel={openCancelFlow}
/>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `subscription` | `SubscriptionView` | — | Subscription data |
| `onUpgrade` | `() => void` | — | Change plan action |
| `onCancel` | `() => void` | — | Cancel action |
| `upgradeLabel` | `string` | `"Change plan"` | Upgrade button label |
| `cancelLabel` | `string` | `"Cancel"` | Cancel button label |
