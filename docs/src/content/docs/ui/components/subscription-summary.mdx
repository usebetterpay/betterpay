---
title: Subscription Summary
description: Current plan, status, next charge, and period end for a subscription.
---

`SubscriptionSummary` shows the active (or past-due) subscription at a glance.

<ComponentPreview
  code={`import { SubscriptionSummary } from '@betterpay/ui';

<SubscriptionSummary
  subscription={subscription}
  onUpgrade={() => {}}
  onCancel={() => {}}
/>`}
>
  <DemoSubscriptionSummary />
</ComponentPreview>

## Installation

```bash title="Terminal"
pnpm add @betterpay/ui
```

```tsx title="Usage"
import { SubscriptionSummary, type SubscriptionView } from '@betterpay/ui';
```

## API Reference

### SubscriptionSummary

| Prop | Type | Default |
| --- | --- | --- |
| `subscription` | `SubscriptionView` | — |
| `onUpgrade` | `() => void` | — |
| `onCancel` | `() => void` | — |
| `upgradeLabel` | `string` | `"Change plan"` |
| `cancelLabel` | `string` | `"Cancel"` |
