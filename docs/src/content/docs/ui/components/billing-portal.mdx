
```tsx title="Full portal"
<BillingPortal
  subscription={subscription}
  plans={plans}
  entitlements={entitlements}
  invoices={invoices}
  usagePeriodLabel="12 days left in cycle"
  invoiceLayout="responsive"
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `subscription` | `SubscriptionView` | — | Current sub |
| `plans` | `PlanView[]` | `[]` | For plan switcher |
| `entitlements` | `EntitlementView[]` | `[]` | Usage meters |
| `invoices` | `InvoiceView[]` | `[]` | History |
| `callout` | `{ status, title?, description? } \| null` | `null` | Banner |
| `onChangePlan` | `(planId) => void` | — | Plan change |
| `onCancel` | `(payload) => void` | — | Cancel |
| `onDownloadInvoice` | `(id) => void` | — | Invoice download |
| `invoiceLayout` | `"table" \| "cards" \| "responsive"` | `"responsive"` | History layout |
| `usagePeriodLabel` | `string` | — | Cycle hint |
| `invoicesLoading` | `boolean` | `false` | Invoice skeleton |
| `usageLoading` | `boolean` | `false` | Usage skeleton when empty |
| `title` | `string` | `"Billing"` | Page title |

Composes: `SubscriptionSummary`, `PlanSwitcher`, `CancelFlow`, `UsageSummary`, `InvoiceTable`, `InvoiceCardList`, `PaymentStatusBanner`.
