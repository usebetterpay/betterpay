## Usage

```tsx title="Import"
import { InvoiceTable, type InvoiceView } from '@betterpay/ui';
```

```tsx title="Basic"
<InvoiceTable
  invoices={invoices}
  onDownload={(id) => window.open(`/invoices/${id}`)}
/>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `invoices` | `InvoiceView[]` | — | Rows |
| `title` | `string` | `"Invoices"` | Heading |
| `emptyMessage` | `string` | `"No invoices yet."` | Empty state |
| `onDownload` | `(invoiceId) => void` | — | Download action |
