`InvoiceTable` is the dense desktop view of billing history.

<ComponentPreview
  fullWidth
  code={`import { InvoiceTable } from '@betterpay/ui';

<InvoiceTable
  invoices={invoices}
  onDownload={(id) => window.open(\`/invoices/\${id}\`)}
/>`}
>
  <DemoInvoiceTable />
</ComponentPreview>

## Installation

```bash
pnpm add @betterpay/ui
```

## API Reference

### InvoiceTable

| Prop | Type | Default |
| --- | --- | --- |
| `invoices` | `InvoiceView[]` | — |
| `title` | `string` | `"Invoices"` |
| `emptyMessage` | `string` | `"No invoices yet."` |
| `onDownload` | `(invoiceId: string) => void` | — |
