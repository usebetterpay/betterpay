`PlanGroup` owns monthly/yearly state and can render a grid of plans, or wrap custom children that call `usePlanGroup()`.

## Installation

```bash title="Terminal"
pnpm add @betterpay/ui
```

```tsx title="Usage"
import { PlanGroup, PlanGroupIntervalToggle, usePlanGroup, PlanCard } from '@betterpay/ui';
```

## Examples

### Controlled interval

```tsx
const [interval, setInterval] = useState<'month' | 'year'>('month');

<PlanGroup
  plans={plans}
  interval={interval}
  onIntervalChange={setInterval}
  onSelectPlan={handleSelect}
/>
```

### Custom children

```tsx
function CustomGrid() {
  return (
    <PlanGroup defaultInterval="month" showIntervalToggle title="Plans">
      <div className="grid gap-4 md:grid-cols-2">
        <InnerCards />
      </div>
    </PlanGroup>
  );
}

function InnerCards() {
  const { interval } = usePlanGroup();
  return plans.map((plan) => (
    <PlanCard key={plan.id} plan={plan} interval={interval} onSelect={...} />
  ));
}
```

## API Reference

### PlanGroup

| Prop | Type | Default |
| --- | --- | --- |
| `plans` | `PlanView[]` | — |
| `interval` | `"month" \| "year"` | controlled |
| `defaultInterval` | `"month" \| "year"` | `"month"` |
| `onIntervalChange` | `(interval) => void` | — |
| `onSelectPlan` | `(planId, interval) => void` | — |
| `currencyFallback` | `string` | `"IDR"` |
| `showIntervalToggle` | `boolean` | `true` |
| `title` | `string` | — |
| `description` | `string` | — |
| `columns` | `1 \| 2 \| 3 \| 4 \| "auto"` | `"auto"` |

### usePlanGroup

```ts
const { interval, setInterval } = usePlanGroup();
```
